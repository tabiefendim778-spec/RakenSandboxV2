# RAKEN SANDBOX V2

Unreal Engine 5 C++ rebuild of RAKEN SANDBOX.

## Milestone 1
- Unreal C++ project skeleton
- Double-precision celestial state model
- N-body gravity solver
- Symplectic integration
- Sun / Earth / Moon bootstrap
- Free/orbit camera foundation
- Quality presets
- Automated startup and smoke-test scaffolding

A release is only considered valid after compile, startup, render, physics and runtime smoke tests pass.
